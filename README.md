# Green Valley Matriculation School — Design Prototypes

Five distinct website design concepts for a fictional school ("Green Valley Matriculation
School," Nagercoil, Tamil Nadu — a placeholder identity), built as static Astro sites for
side-by-side comparison.

All school names, contact details, statistics, dates, and staff names are placeholders and
are clearly marked as such throughout the site.

## Prototypes

| Concept | Path |
| --- | --- |
| The Learning Garden | `/learning-garden/` |
| Bright Futures | `/bright-futures/` |
| A School Day Story | `/school-day-story/` |
| Little Explorers | `/little-explorers/` |
| Roots and Horizons | `/roots-and-horizons/` |

The root page (`/`) links to all five.

## Development

```sh
npm install
npm run dev
```

Then open `http://localhost:4321`.

## Build

```sh
npm run build
npm run preview
```

`npm run build` outputs a static site to `./dist/`, deployable to any static host.
